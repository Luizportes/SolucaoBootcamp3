# Test Harness

## Objetivo

O Test Harness foi criado para automatizar a validação da API inicial do projeto, verificando o comportamento esperado das rotas e identificando possíveis falhas durante o desenvolvimento.

## Tecnologias

- Node.js
- Jest
- Supertest
- Express
